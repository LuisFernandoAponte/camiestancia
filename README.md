# 🐄 Hacienda Guayabal Lorente - Sistema de Gestión Ganadera

Sistema integral de gestión ganadera para bovinos de élite en Santa Cruz, Bolivia.

## 🚀 Arquitectura del Proyecto

- **Frontend:** React + Vite + TanStack Start (Desplegado en Vercel)
- **Backend:** Node.js + Hono API (Desplegado en Render)
- **Base de Datos:** Cloud PostgreSQL en Supabase
- **Almacenamiento:** Cloudinary
